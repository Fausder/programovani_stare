Detailed Description

Třída reprezentující jádro procesoru.

Tato třída simuluje chování výpočetního jádra procesoru, které může zpracovávat úlohy různých typů. Každý typ jádra má optimální výkon pro odpovídající typ úlohy.

◆ processTimeUnit()

bool Core::processTimeUnit ( )

Posune simulaci o jednu časovou jednotku.

Tato metoda simuluje jednu časovou jednotku zpracování úlohy. Pokud jádro zpracovává úlohu, sníží se zbývající čas o jednu jednotku. Pokud tím úloha dosáhne nuly, je dokončena a odstraněna z fronty.

Returns
True pokud byla dokončena úloha, jinak false
